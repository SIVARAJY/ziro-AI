CertiCheck

A certificate checking agent for recruiters. It confirms candidate consent, asks a person to approve the lookup, reads the issuer’s verification page, and compares what it finds with the candidate’s claim. A missing record is reported as “not found”, never as “fake”.

    How it works

    Pipeline: intake and validation, consent gate, planner, human approval, retriever, verifier, result store. Each result keeps the source URL, retrieval time, the page snapshot, extracted values and the reason for the decision. Repeat requests for the same approved check reuse the stored result instead of running a second lookup. The retriever reads a mock issuer registry that stands in for a public course platform page; it never touches OTP or CAPTCHA steps.
